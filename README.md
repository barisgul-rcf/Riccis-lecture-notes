# Riccis-lecture-notes
Lecture notes compiled by the noble and wise elephant Ricci from various articles.

Ricci believes that knowledge should never be bound by any chains and that accessing it should be made easier; therefore, he shares all his notes with the esteemed reader as a public domain under the Creative Commons Zero Universal license. You are free to copy, modify, and distribute my personal lecture notes without any permission.

All compiled articles included in this repository are **Open Access** and properly cited in the references. The CC0 license of this repository applies *only* to my original lecture notes and compilations, not to the full texts of the individual articles themselves.
